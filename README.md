# Discord Job & Freelance Manager 🚀

Automated Discord Job & Freelance Management Platform powered by **9Router AI Engine** and Playwright.

## ✨ Features
- **Discord Channel Ingestion**: Seamless ingestion and deduplication from Discord channels (`1501058754630910102`, `1500464207479701624`).
- **AI Cover Letter & Proposal Generation**: Generates customized cover letters using 9Router models.
- **AI Captcha Solving**: Vision AI powered captcha resolution during automated submissions.
- **Headless Browser Auto-Apply**: Playwright stealth engine for form navigation and filling.
- **Modern Dark-Mode Dashboard**: Real-time filtering, metric counters, applicant profile settings.

## 🛠️ Stack
- Node.js & Express
- SQLite (WAL Mode)
- 9Router AI Engine (Local Host / API Gateway)
- Playwright Headless Automation
- Tailwind CSS & FontAwesome

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start server
npm start
```
